# ADRs

Architecture Decision Records capture durable technical choices for this repo.

## Rules

- Use four-digit numbering: `NNNN-short-title.md`.
- Keep one decision per file.
- Update the status when a decision changes.
- Cross-reference companion repo decisions by title, not by ADR number.

## Status meanings

- `Proposed`: under review, not yet enforced everywhere.
- `Accepted`: chosen and expected to guide implementation.
- `Superseded`: replaced by a newer ADR.
- `Deprecated`: still relevant historically, but no longer recommended.
