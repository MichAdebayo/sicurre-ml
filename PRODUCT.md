# Monitoring Product Context

## Register

product

## Users

Sicurre operators and certification reviewers inspecting the ML runtime.

## Product Purpose

Distinguish service availability, inference performance and resource pressure
in one desktop screenshot, with detailed diagnostics available below.

## Brand Personality

Restrained, precise, readable. Preserve Grafana's native visual conventions.

## Anti-references

Mixed health and activity cards, unexplained semantic colors, fabricated traffic,
stale green indicators, and summaries that hide the charts below the fold.

## Design Principles

- Show measured states; distinguish failures from missing telemetry.
- Separate current health from selected-period inference statistics.
- Keep four charts visible with compact status and resource rows.
- Name the measured boundary: process, HTTP endpoint, model or collector.

## Accessibility & Inclusion

Pair state colors with readable text in both Grafana themes. Keep a stable,
legible type scale and verify screenshots without browser zoom tricks.
